Calculator notebook

The notebook of the calculator's home screen (saved under a name or not), shown and edited here like a Jupyter notebook; its cells run on the calculator, connected by its USB cable. The calculator and this page are two views of one notebook: what you change on one shows on the other. This page is one file (CALCULATOR.HTML on the calculator's CALC drive): it needs no installation and no network, and it never sends anything anywhere but to the calculator.

Connect

  1. Connect the calculator to the computer with a USB cable (the CALC drive appears).
  2. Open CALCULATOR.HTML in Chrome or Edge (Safari and Firefox can open notebooks to read them, but cannot talk to the calculator). You can also copy the file to the computer first.
  3. Click Connect and choose the calculator in the list. The dot turns green and the page shows the notebook of the calculator's home screen (Unsaved until it has a name). The calculator stays on the screen it shows.

The page remembers the permission: next time it connects by itself. If the calculator leaves the USB bus for a moment (it refreshes its drive after a module was installed, or restarts), the page reconnects on its own and reads the notebook again. Not connected, the page shows the notebook as it last saw it, read-only.

One notebook, two views

  • Both always have the same notebook, the calculator's home screen's: opening, creating or switching one on either side switches the other. Notebooks lists the calculator's notebooks (open, rename, delete); New makes one there. A name typed for an unsaved notebook saves it under that name.
  • Calculations, cells and graphs made on the calculator's home screen appear here as they are made; what you add or run here appears there. The calculator may show other apps meanwhile: this page keeps working.
  • A cell being edited on one side cannot be edited on the other: here it says editing on the calculator and shows the typing as it goes; the calculator says being edited in the browser. It is free again when the editing ends (Esc), or 30 seconds after the page went quiet.
  • Running a cell, here or on the calculator, runs it once on the calculator. Its results show on both. Interrupt, Run all and Restart work from either side.
  • The calculator saves a named notebook when it is switched off (also on a low battery), when another notebook is opened, before an export, and two minutes after the last change. Meanwhile a dot after the name says there are unsaved changes.

Cells

PythonRuns in the calculator's Python (MicroPython with the calc library). Variables stay until Restart. The value of the last line is shown as the result, typeset when it is a CAS expression. calc.plot(f, a, b) is drawn here too.
MathOne line of CAS input, e.g. solve(x^2-2=0, x), integrate(1/(1+x^2), x), f(x):=x^2; Enter runs it. The result is typeset. It uses the calculator's CAS variables and settings.
GraphA graph cell, made here or on the calculator's home screen: its functions of x, one a line (Enter starts a new line), and its x and y range under it, in the calculator's colours. The calculator computes the values; the page draws them. Drag to pan, pinch or (after a click on the graph) use the wheel to zoom, double-click to go back: the calculator's cell gets the new window when you let go. While the calculator's graph app is open on the cell it is read-only here.
3D graphz = f(x,y), e.g. sin(x)*cos(y), and its x, y, z range: a 3D graph cell on the calculator too. The surface is computed on the calculator (40 × 40 values) and drawn here: drag to turn it, wheel or pinch to zoom, double-click for the cell's view (the calculator's view does not change). Parametric surfaces and curves show the calculator's picture.
Animated graphA Graph or 3D graph cell whose functions use t, e.g. sin(x-t): it plays here at once, from frames the calculator computes in one go. Play / pause, the slider moves t by hand, the menu sets the speed: those are this page's (the calculator plays its cell only when you press F5 there). Under the cell: t from, to, the seconds a sweep and loop, bounce or once, the cell's own settings on both sides.
Earlier resultsOut[n] is the result of cell [n] (In [n] here, [n] on the calculator: one count), Ans the latest result, in Math and Python cells alike (in Python Out maps the numbers to the values). Hover over an input or a result: insert text and insert Out[n] put it where you type, or into a new cell.
TextMarkdown: # heading, **bold**, *italic*, lists, tables, `code`, math $x^2$ and $$\int_0^1 x\,dx$$.

Keys

Like Jupyter: edit mode (green bar) types into the cell; command mode (blue bar) works on cells. Esc leaves the cell, Enter goes into it.

Shift+Enterrun the cell, go to the next one (a new cell at the end)
Ctrl+Enterrun the cell, stay
Alt+Enterrun the cell, insert a cell below
Tab / Shift+Tab(edit mode) indent / dedent the lines
Alt+↑ / Alt+↓(edit mode) the inputs of the cells above of this kind, nearest first, in place of the text
Ctrl/Cmd+Ssave a copy on the computer (with Shift: save as)
↑ ↓ or K J(command mode) previous / next cell; Shift+K / J move the cell
A / Binsert a cell above / below
D,D / Zdelete the cell / undo the delete
X C Vcut, copy, paste below (Shift+V: above)
Y T G Mmake it a Python, Math, Graph or Text (Markdown) cell
Shift-Gmake it a 3D graph cell (z = f(x,y))
I,Iinterrupt (as the calculator's ON key: KeyboardInterrupt)
0,0restart Python (its variables are lost)
O / Hhide or show the cell's output / this help

Files

Notebooks are Jupyter files (.ipynb, nbformat 4.5). Open (or a file dropped on the page) sends a notebook file from the computer to the calculator, under the file's name (a notebook of that name there is replaced; its previous version is kept), and opens it on both. Save writes the calculator's notebook to a file on the computer (Chrome and Edge ask for permission once), Download saves a copy: with the outputs, plots as pictures, so Jupyter shows them too. Not connected, Open shows a file here to read.

If something does not work

  • The calculator is not in the list: check the cable (some cables only charge); another program (a terminal) may have the port open.
  • The page says the calculator has no Notebook: install the Python module (Memory > Modules on the calculator, or drop its .MOD file on the CALC drive).
  • A cell runs for ever: Interrupt (or the ON key on the calculator).
