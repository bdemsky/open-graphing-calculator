# Power cycles (SHIFT ON, ON: save, then restart from the session) in the
# middle of work in the Phase 2 apps, menus and help: the calculator comes
# back on the home screen with the saved state. Lines being typed in a
# spreadsheet cell or the list editor are dropped, entries typed into
# editors that hold them (3D z=, home, RPN command line) are kept.
app sheet
sheet set A1 2
type "=A1*3"
key SHIFT ON
key ON
expect screen home
app sheet
expect state sheet_mode browse
sheet expect A2 ""
