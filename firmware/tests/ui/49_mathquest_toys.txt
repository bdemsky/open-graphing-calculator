# Sparkle Town's toy box (modules/mathquest/mq_toys.c): toys where the numbers are the toy --
# Bongo Beats (a rhythm game with Puff the drum sheep), the jam, the kaleidoscope, the magic
# square, the cage puzzle, number magic, growing dots, the mandala and the secret code.
# Deterministic with `mq seed` and `mq step`; the drums fire their sound hooks.
requirecfg CONTENT_QSPI
fs insert 64
fs format
module library extra
module install /CALC/MODULES/{mod:mathquest}
key CLEAR
app mathquest
modx sfx clear
mq seed 5
mq fun off
mq new Mia 2
mq go arcade
mq step 4
screenshot mq_arcade.png
touch tap 160 202
expect state mq_scene toys
mq step 4
screenshot mq_toys.png
