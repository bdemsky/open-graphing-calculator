# Drag to scroll on every scrolling screen (app/touch_scroll.c): the content
# follows the finger (finger up shows later rows, finger left later columns),
# one row / column per row height / column width, the focus is pulled along
# so it stays visible, and a drag never acts like a tap.
# --- home (Textbook view): drag down shows older history, any key returns
type "111+0\n222+0\n333+0\n444+0\n555+0\n666+0\n777+0\n888+0\n"
expect notext 222+0
touch drag 160 40 160 140 8
expect text 222+0
expect notext 888+0
expect state home_sel -1
key 1
expect text 888+0
expect notext 222+0
key CLEAR
# a selected entry pushed off the bottom hands the selection to one on screen
key UP
expect state home_sel 15
touch drag 160 40 160 140 8
expect state home_sel 12
key CLEAR CLEAR
