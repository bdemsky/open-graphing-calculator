# Michael Wester's CAS benchmark ("A Critique of the Mathematical Abilities of
# CA Systems", in M. Wester (ed.), Computer Algebra Systems: A Practical Guide,
# Wiley 1999), translated to this CAS's syntax.
#
# Provenance
#   Primary source: Wester's own Macsyma transcripts of the test suite,
#   http://math.unm.edu/~wester/demos/<Section>/Macsyma.problems (25 sections,
#   fetched 2026-10; linked from http://math.unm.edu/~wester/cas_review.html).
#   The expected answers are the "=> ..." comments in those files.
#   Cross-checked against SymPy's transcription
#   sympy/utilities/tests/test_wester.py (SymPy 1.14.0, in .venv), whose
#   expected values were used where Wester's comment is informal; problem ids
#   follow SymPy's lettering (A logic, B sets, C numbers, D numerical analysis,
#   E statistics, F combinatorics, G number theory, H algebra, I trig,
#   J special functions, K complex domain, L zero equivalence, M equations,
#   N inequalities, O vectors, P matrices, R sums, S products, T limits,
#   U calculus, V indefinite integrals, W definite integrals, X series,
#   Y transforms, Z difference/differential equations).  Numbers within a
#   section follow Wester's order, so they do not always equal SymPy's.
#   Corrections: C21 uses (41+29*sqrt(2))^(1/5) (Wester's file has a typo,
#   49+21*sqrt(2)); Y4 uses 1/s - exp(-6*sqrt(s))/s (the transform of erf, the
#   comment gives the one of erfc); M26 follows SymPy's corrected equation.
#
# Format: one block per problem
#   @section <letter> <name>
#   == <id> | <title>
#   pre:  <line>        setup lines sent before the graded line (repeatable)
#   in:   <line>        the graded input (several in: lines = pre + last in)
#   expect: <answer>    in this CAS's syntax (also parsed by SymPy: ^, ln, i,
#                       e, pi, inf); SymPy names allowed (LambertW, besselj..)
#   check: <kind ...>   how to grade (default exact), see run_wester.py:
#       exact      equivalent and not merely numeric
#       value      equivalent within tol (floats fine)      rel  relative tol only
#       simp       equivalent and no bigger (count_ops) than expect (+slack)
#       form       equivalent and structurally equal to expect after SymPy parse
#       factor     equivalent and same number of non-constant factors
#       terms N    equivalent and a sum of N terms
#       set        solution list, order-free (set distinct: ignore multiplicity)
#       satisfy    every solution makes `eq` vanish; all `need` values present
#       ineq       truth sets agree at sample points of var
#       antideriv  d/dvar(output) equals expect (the integrand)
#       ode N      expect = residual in Y, Y1, Y2 (solution and derivatives),
#                  ic: list of residuals; N = number of free constants c1..cN;
#                  implicit solutions F(x,y)=c are checked by implicit diff.
#       odesys N   expect = residual list in U, V, W (solutions for u, v, w)
#       linsys N / nlsys N  substitute into the input system; N free vars /
#                  N solutions
#       eigvecs N  M v = lambda v for each vector, N vectors in all
#       span       same span as the expected basis
#       matsq      output squared equals the expected matrix
#       oneof      equivalent to one of the listed alternatives
#       asym E     |output-expect| * var^E -> 0 as var -> inf
#       logic      boolean equivalent to expect and no bigger
#       rect       equivalent, i only outside function arguments (a+b*i form)
#       bool / str exact text;  error  an error or divergence is the answer
#       curlof     a list [A1,A2,A3] whose curl in x, y, z equals expect
#       manual     graded by hand (see override:)
#   domain: v=pos|neg|real|int|big|lo:hi   sampling domain of a symbol
#   allow: names        function names allowed in the output (unknown f, g..)
#   alt: CAT | output | note     classify this exact output as CAT
#   override: CAT | reason       manual classification after review
#   na: reason          not applicable to this CAS (excluded from the score)
#   unsupported: reason no plausible input exists (feature absent)
#   note: free text
