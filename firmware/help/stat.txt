%% Statistics app: lists, CALC, TESTS, DISTR, stat plots, CSV on microSD (app/stat_*.c)

@page stat Statistics app
{apps} > Statistics opens the STAT menu, {apps} > Distributions the [[stat-distr|DISTR]] menu and {apps} > Stat plots (also {shift} {F1} on the graph screens) the [[stat-plots|STAT PLOTS]]. In the list editor the soft keys reach all of them: stat, calc, tests, plots, graph; {shift}: sortA, sortD, clrlist, csv, distr.

- Edit lists...: the [[stat-edit|list editor]] (L1..L6 and named lists)
- CALC: [[stat-calc|1-Var and 2-Var statistics]], [[stat-regression|regressions]]
- TESTS: [[stat-tests|hypothesis tests]] and [[stat-intervals|confidence intervals]]
- SortA, SortD, ClrList, SetUpEditor: see [[stat-edit]]
- Stat plots, CSV on microSD: [[stat-plots]], [[stat-csv]]

A typical session: enter data in the list editor, {F2} calc > 1-Var Stats, {F5} (calc). For a fit, calc > LinReg(ax+b), {F5}, then {F2} (plot) on the result shows the points and the fitted line on the graph.

Lists are also CAS variables: see [[stat-lists]]. Results of the last computation are in {vars} > Statistics ([[stat-results]]). The distribution functions are listed in [[stat-cmds]].

@page stat-lists Lists
The lists L1 to L6 always exist; RESID receives the residuals of the last regression; up to 13 more named lists (1 to 7 letters and digits, e.g. `DATA`) can be created in the [[stat-edit|list editor]] or by a CSV import. A list holds up to 999 numbers and is saved when the calculator is switched off.

On the home screen a list name is a CAS variable:

    mean(L1)
    L1*2→L3
    {1,2,3}→L2
    sort(L2)→L2
    normalcdf(L1,L1+1)

Storing into a list name (`→` or `:=`) updates the list editor. Lists can be inserted from {vars} > Lists.

@page stat-edit List editor
STAT > Edit lists... shows the lists in columns; the line at the bottom edits the highlighted cell.

- Arrows move; typing a number or expression and {enter} stores it and moves down; below the last element adds one. When nothing is selected for display, the bottom line says in grey what the highlighted place takes.
- {⌫} deletes the element, {shift} {⌫} (ins) inserts a 0.
- On a list name (top row), {enter} shows the whole list `{1,2,3}`. Type an expression such as `L1*2` and {enter} to fill the list once, or the expression in quotes, `"L1*2"`, to attach a column formula: the list then recomputes whenever another list changes (a `*` after the name marks it). {clear} {enter} on the name clears the list. {⌫} on a name removes the column from the editor (the list is kept).
- The column `+ new` after the last list takes the name of a new named list.
- SortA / SortD sort the highlighted list (from elsewhere: a form, with lists to carry along). ClrList empties the highlighted list after a No/Yes question (from elsewhere: a form naming the lists); SetUpEditor restores the columns L1..L6.

@page stat-calc 1-Var and 2-Var statistics
STAT > CALC > 1-Var Stats asks for a list and an optional frequency list (`1` = none) and shows xbar (mean), Σx, Σx², Sx (sample standard deviation), sigmax (population standard deviation), n, minX, Q1, Med, Q3, maxX and the mode (the value with the largest frequency; `-` when all values are equally frequent). Each result line says in grey what the value is.

Quartiles are the medians of the lower and upper halves (the usual calculator convention).

2-Var Stats takes an X and a Y list and adds ybar, Σy, Σy², Sy, sigmay, Σxy, minY, maxY.

@page stat-regression Regressions
STAT > CALC: LinReg(ax+b), LinReg(a+bx), QuadReg, CubicReg, QuartReg, LnReg (a+b ln x), ExpReg (a*b^x), PwrReg (a*x^b), Logistic (c/(1+a*e^(-bx))), SinReg (a*sin(bx+c)+d) and Med-Med.

The form takes the X and Y lists, a frequency list (`1` = none) and RegEQ->, a Y= function to receive the equation (for graphing it with a [[stat-plots|scatter plot]]). The result shows the coefficients, r² or R² and r where defined; the residuals y - f(x) are stored in RESID and the equation is in {vars} > Statistics > RegEQ.

{F2} (plot) on the result graphs the fit in one step: the equation goes to the RegEQ function, or, when none was chosen, to the first empty Y= function (a function in use is never overwritten); a stat plot shows Xlist against Ylist as a scatter plot (the plot already doing so, else the first plot that is off, else Plot1); ZoomStat fits the window.

LnReg, ExpReg and PwrReg fit a line to the logarithms (the usual calculator convention); Logistic and SinReg are nonlinear least squares fits.

@page stat-tests Hypothesis tests
STAT > TESTS: Z-Test, T-Test, 2-SampZTest, 2-SampTTest, 1-PropZTest, 2-PropZTest, chi² GOF-Test, chi²-Test, 2-SampFTest, LinRegTTest, ANOVA.

- Input: Data takes lists, Stats takes xbar, Sx and n. Ha: is the alternative hypothesis, written out (`mu≠mu0`, `mu<mu0`, `mu>mu0`; `p`, `sd`, `slope` for proportions, standard deviations and the slope), chosen with {◀} {▶}. {F5} (calc) computes and {F4} (draw) draws from anywhere in the form. Empty fields show `(enter a value)`; the line at the bottom says what the highlighted field takes, or what is wrong.
- Calculate shows the statistic, p and df, with the hypothesis tested at the top right (`Ha: mu>5`); Draw shades the p-value region ([[stat-results]]).
- 2-SampTTest: Pooled Yes assumes equal variances; No uses Welch's df.
- chi² GOF-Test: observed and expected lists and df; the contributions go to the list CNTRB.
- chi²-Test: Observed is a matrix such as `[[10,20],[30,40]]` or the name of a CAS variable holding one; the expected counts are stored in the CAS variable `chi2exp`.
- LinRegTTest tests the slope of LinReg(ax+b) and shows a, b, s, r², r.
- ANOVA: Lists names the groups, e.g. `L1,L2,L3`.

@page stat-intervals Confidence intervals
STAT > TESTS: ZInterval, TInterval, 2-SampZInt, 2-SampTInt, 1-PropZInt, 2-PropZInt. Inputs as for the [[stat-tests|tests]]; C-Level is the confidence level, `0.95` or `95`. The result shows lower, upper, the margin of error ME and the sample statistics.

@page stat-results Results
Results are listed one per line ({▲} {▼} scroll), each with its meaning in grey (mean, sample std. dev., p-value, ...). The top right shows the alternative hypothesis of a test, the confidence level of an interval or the Y= function that got a regression equation.

- {F1} (draw) or {enter}, for a test: the distribution with the p-value region shaded.
- {F2} (plot), for a regression: the data and the fitted curve on the graph ([[stat-regression]]).
- {clear} or {F5} (back): back to the form.

{vars} > Statistics lists the values of the last result (xbar, Sx, p, z, a, b, r², ...) and RegEQ, the last regression equation; choosing one inserts it at the cursor.

@page stat-distr Distributions
{apps} > Distributions (DISTR; {shift} {F5} in the list editor) inserts the [[stat-cmds|distribution functions]]: normalpdf, normalcdf, invNorm, invT, tpdf, tcdf, chi2pdf, chi2cdf, Fpdf, Fcdf, binompdf, binomcdf, poissonpdf, poissoncdf, geometpdf, geometcdf, invChi2, invF. The menu shows the order of the arguments (in square brackets: optional, e.g. `normalcdf(lo,hi[,mu,sd])`) and inserts the name with its parentheses, the cursor inside. They work on the home screen in exact and approximate mode, in Y= functions (graph `normalpdf(x)`), in lists and in forms.

For a normal probability such as P(-1 ≤ X ≤ 1): DISTR > normalcdf, type `-1,1` (for a mean of 100 and a standard deviation of 15: `85,115,100,15`), {enter}; or DRAW > ShadeNorm to see the area too.

DRAW > ShadeNorm, Shade_t, Shadechi², ShadeF draw the density with the area between lower and upper shaded and print the area. Use `-1E99` / `1E99` (or `-inf` / `inf`) for unbounded tails.

Relative accuracy: about 1E-12.

@page stat-plots Stat plots
{shift} {F1} (plots) on a graph screen or {F4} (plots) in the list editor lists Plot1..Plot3, PlotsOff, PlotsOn and ZoomStat. A plot has:

- Type: Scat (scatter), Line (xyLine), Hist (histogram, bar width Xscl), MBox (modified box plot, outliers marked), Box, NPrb (normal probability plot); on the Type row the bottom line says what the chosen type draws
- Xlist, Ylist (scatter and line), Freq (histogram and box plots, `1` = none)
- Mark: box, + or dot (types that draw points); Color 1..8, shown as the Y= colours

Rows a type does not use are hidden. Plots are drawn on the [[graph]]; ZoomStat ({F5}) fits the window to their data, {F4} (graph) shows the graph as it is. New plots are red, green and magenta, so they stand out from a regression line in Y1 (blue).

@page stat-csv CSV files on the microSD card
STAT > CSV on microSD:

- Export lists...: the lists named in Lists (e.g. `L1,L2,DATA`) go to File (8.3 name, e.g. `LISTS.CSV`) in the card's root folder, one column per list, the names in the first row.
- Export all lists: every non-empty list to `ALL.CSV`.
- Import CSV...: choose a .CSV file in the root folder. A first row with text names the columns: L1..L6, RESID or a valid list name (created if needed); other columns go to L1, L2, ... in order. Commas, semicolons or tabs separate the values (with semicolons or tabs a decimal comma is accepted). The list editor then opens on the first imported list.
- Card info: file system, size and free space.

FAT16 and FAT32 cards (up to 32 GB) are supported. A file replaces its old version only when completely written: removing the card during a write keeps the old file. Card errors say what to do (insert a card, format it as FAT32, use an 8.3 name such as `DATA.CSV`).

@cmd normalcdf
group: stat-cmds
summary: Normal probability of an interval
syntax: normalcdf(lower, upper)
syntax: normalcdf(lower, upper, mu, sigma)
example: normalcdf(-1,1)
result: 0.682689492137
example: normalcdf(-inf,110,100,15)
result: 0.747507462453

## Refresher
P(a < X < b) for X ~ Normal(μ, σ) = Φ((b − μ)/σ) − Φ((a − μ)/σ), Φ(z) = (1 + erf(z/√2))/2. About 68 %, 95 %, 99.7 % within 1, 2, 3 σ; 95 % within 1.96 σ. Use −inf or inf for a one-sided probability.
example: normalcdf(-1.96,1.96)
result: 0.950004209704
## Syntax
P(lower ≤ X ≤ upper) for a normal X; `-inf`, `inf` or ±1E99 for tails. Tail areas are computed directly, so small probabilities are accurate.

@cmd binompdf
group: stat-cmds
summary: Binomial probability
syntax: binompdf(n, p, x)
syntax: binompdf(n, p)
example: binompdf(10,0.3,3)
result: 0.266827932
example: binompdf(4,1/2,2)
result: 3/8
example: binompdf(3,1/2)
result: [1/8,3/8,3/8,1/8]
see: binomcdf

## Refresher
P(X = k) = C(n,k) p^k (1 − p)^(n−k) for the number of successes in n independent trials; mean np, variance np(1 − p). Approximately Normal(np, √(np(1−p))) when both np and n(1−p) are large, Poisson(np) when p is small.
example: binomcdf(10,0.5,5)
result: 0.623046875
## Syntax
P(X = x) for X binomial with n trials and success probability p; without x, the list for x = 0..n. With exact p in exact mode the result is exact.

@cmd exppdf
group: stat-cmds
summary: Exponential probability density
syntax: exppdf(x, rate)
example: exppdf(1,2)
result: 2/exp(2)
see: expcdf, invExp

## Refresher
The waiting time between events of a Poisson process with rate λ: f(x) = λ e^(−λx) for x ≥ 0, mean 1/λ, P(X ≤ x) = 1 − e^(−λx). Memoryless: P(X > s + t | X > s) = P(X > t).
example: exppdf(0.5,1)
result: 0.606530659713
## Syntax
Density at x (0 for x < 0). Exact for exact arguments. These distribution commands live in the advanced CAS module.

@cmd gammapdf
group: stat-cmds
summary: Gamma probability density
syntax: gammapdf(x, k, theta)
example: gammapdf(2,3,2)
result: 1/(4*e)
see: gammacdf, invGamma, chi2pdf

## Refresher
Gamma with shape k and scale θ: f(x) = x^(k−1) e^(−x/θ)/(gamma(k) θ^k) for x > 0; mean kθ, variance kθ². For integer k it is the sum of k exponential waiting times with mean θ (Erlang); χ² with n degrees of freedom is gamma(n/2, 2).
## Syntax
Density at x (shape k > 0, scale theta > 0; the rate is 1/theta). Exact for exact arguments.
